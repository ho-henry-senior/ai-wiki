# From CLI agents toward a lightweight software factory

This is a working path through the knowledge base, not a prescribed maturity model. It will connect relevant pages as they are written, tracing the questions involved in moving from a single agent in a CLI to multiple agents in distinct roles and, eventually, automation.

As work becomes more distributed across agents, see [Define agent role responsibilities and boundaries](agent-role-boundaries.md) for a way to make each role's expected work and limits explicit.
