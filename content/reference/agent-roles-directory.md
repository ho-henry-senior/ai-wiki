# Agent roles directory

**Roles are less established than skills.** A role defines responsibility and handoff boundaries; a skill defines a reusable task procedure. Neither grants or restricts technical permissions on its own. See [skills, profiles, and tools have different jobs](../concepts/skills-profiles-and-tools.md).

The proposed first collection draws on the [lo-fi software factory case study](../articles/lo-fi-software-factory-case-study.md):

- **Product** — product intent and scope decisions.
- **Business analyst** — requirements, acceptance criteria and open questions.
- **Developer** — agreed implementation and verification evidence.
- **Reviewer** — independent inspection of the change and its tests.

These are **provisional descriptions**, not transcriptions of the original role definitions. Once the four source Markdown files are available, this page should link to each original asset, its author or maintainer, and show what it owns, hands off, and leaves for human approval. Do not manufacture role configurations before inspecting those files.

See [from agile roles to agent-assisted workflows](../articles/agent-role-boundaries.md) for the wider distinction between responsibilities and tools.
