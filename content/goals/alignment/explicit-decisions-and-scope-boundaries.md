# Explicit decisions and scope boundaries

Agents can identify missing requirements, but they can also suggest features, edge cases and complexity that the work doesn't need. **Requirements discovery is a negotiation:** the agent helps explore the possibilities, but you decide the scope.

Challenge unnecessary suggestions and explicitly agree what's in and out; an excluded idea may still be worth pursuing later. Excluding work isn't just about saving effort; it leaves more time to refine requirements, work through edge cases and verify what matters.

Record those boundaries in the specification so the agent doesn't quietly reintroduce excluded work later.
