# Agent roles and skills

A **skill** is a reusable procedure for one kind of task, which the agent loads when a task needs it. An **agent role** is a responsibility: what an agent is for, where its work stops, and what it hands back. A role can use skills to do its work, but neither needs the other.

Start with skills if you want an agent to do a recurring task the same way each time. Start with agent roles if you want separate agents for separate responsibilities, such as one that implements and another that reviews.
