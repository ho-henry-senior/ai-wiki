# Skills and agent roles

A skill and an agent role solve different problems. A **skill** packages a reusable procedure; a **role** defines a responsibility, a handoff and the tools available to the agent performing it. You can use either independently, or combine them when work repeatedly needs both a specialist responsibility and a dependable procedure.
