# Skills and agent roles

A skill and an agent role solve different problems. A **skill** packages a reusable procedure; a **role** defines a responsibility, a handoff and the tools available to the agent performing it. You can use either independently, or combine them when work repeatedly needs both a specialist responsibility and a dependable procedure.

## Choose the right level of customization

Use a [skill](../goals/economy/useful-skills.md) when you want a repeatable procedure that different agents or tasks can share. Use a [role](../concepts/skills-profiles-and-tools.md) when you need a defined responsibility, toolset and handoff. A role may use a skill, but neither requires the other.

The [Skills guide](../goals/economy/useful-skills.md) explains when to add a skill, how to write one, and where to find examples. The [Agent roles guide](agent-roles.md) covers responsibilities, handoffs, and role-specific examples, including [How agent roles use skills](../reference/agent-roles-directory.md).
