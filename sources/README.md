# Sources

This directory records resources that inform the knowledge base. Keep provenance lightweight: enough to find a resource again and judge whether it may have changed.

## Source index

Add simple links here with a title and, when useful, a short note. Give a resource its own Markdown file when it needs substantive notes, relevant sections or timestamps, or a more durable record. Prefer linking to the original over copying it.

Authored pages can link to sources selectively, especially where a source supports an important, time-sensitive, or contested point.
